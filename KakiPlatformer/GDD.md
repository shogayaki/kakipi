# KakiPlatformer - Game Design Document (GDD)

**バージョン**: 1.0
**作成日**: 2026-03-27
**エンジン**: Unity 2022.3 LTS (2D URP)

---

## 1. ゲーム概要

| 項目 | 内容 |
|---|---|
| タイトル | KakiPlatformer |
| ジャンル | 2Dサイドスクロールアクションプラットフォーマー |
| ターゲット | カジュアルゲーマー（全年齢） |
| プレイ時間 | 約15〜20分（3ステージクリア） |
| プラットフォーム | PC（Windows/Mac）/ WebGL |

### キャッチコピー
「軽快なジャンプと爽快な攻撃で、3つの世界を駆け抜けろ！」

---

## 2. プレイヤーキャラクター仕様

### 基本ステータス
| パラメータ | 値 | 備考 |
|---|---|---|
| HP | 5 | ハートアイコンで表示 |
| 移動速度 | 5.0 m/s | SerializeField で調整可 |
| ジャンプ力 | 12.0 | Rigidbody2D への力 |
| 二段ジャンプ | あり | 空中で1回追加ジャンプ可能 |
| 無敵フレーム | 1.5秒 | ダメージ後の無敵時間 |
| 攻撃範囲 | 前方1.2m | 近接攻撃（剣振り） |
| 攻撃クールダウン | 0.4秒 | 連打制限 |
| 攻撃ダメージ | 1 | 敵に与えるダメージ |

### 操作方法
| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | A/D または ←/→ | 左スティック / 十字キー |
| ジャンプ | Space | A/Cross ボタン |
| 攻撃 | Z または J | X/Square ボタン |
| ポーズ | Escape | Start/Menu |

### 状態遷移
```
Idle ←→ Walk → Jump → Fall → Land → Idle
                ↓
            Attack (攻撃、地上・空中両対応)
                ↓
             Hurt (ダメージ受け)
                ↓
              Dead (死亡)
```

## 3. 敵キャラクター仕様

### 3.1 スライム（SlimeEnemy）
| パラメータ | 値 |
|---|---|
| HP | 1 |
| 移動速度 | 1.5 m/s |
| 接触ダメージ | 1 |
| AI | 左右往復歩行（壁・端でUターン） |
| 出現ステージ | Stage 1, 2, 3 |

### 3.2 ジャンプスライム（JumpEnemy）
| パラメータ | 値 |
|---|---|
| HP | 2 |
| 移動速度 | 2.0 m/s |
| ジャンプ力 | 8.0 |
| ジャンプ間隔 | 1.5秒 |
| 接触ダメージ | 1 |
| AI | プレイヤー方向へジャンプ移動 |
| 出現ステージ | Stage 2, 3 |

### 3.3 コウモリ（FlyingEnemy）
| パラメータ | 値 |
|---|---|
| HP | 1 |
| 移動速度 | 2.5 m/s |
| 接触ダメージ | 1 |
| AI | プレイヤーと同じ高さで水平追跡 |
| 重力 | 0（浮遊） |
| 出現ステージ | Stage 2, 3 |

### 3.4 ボス（BossEnemy）
| パラメータ | 値 |
|---|---|
| HP | 15 |
| フェーズ1 HP | 15〜8 |
| フェーズ2 HP | 7〜0 |
| 接触ダメージ | 2 |
| **フェーズ1 AI** | 左右移動（速度3.0）+ 2.5秒おきにジャンプ |
| **フェーズ2 AI** | 速度4.5 + 1.5秒おきに弾3発発射 |
| 弾ダメージ | 1 |
| 弾速度 | 8.0 m/s |
| 出現ステージ | Stage 3（ボスルーム） |

## 4. ステージ設計

### Stage 1: 草原の丘
- **テーマ**: 緑の草原、晴れ空
- **難易度**: ★☆☆（チュートリアル相当）
- **長さ**: 約80マス幅
- **ギミック**: 移動足場、小さな穴
- **敵**: スライム × 8
- **コイン**: 20枚
- **目標**: ゴールの旗に到達

**エリア構成**:
1. スタートエリア（移動・ジャンプ練習）
2. 連続ジャンプエリア（ステップ状の足場）
3. 敵集中エリア（スライム複数）
4. 動く足場エリア
5. ゴールエリア

---

### Stage 2: 暗黒の洞窟
- **テーマ**: 地下洞窟、薄暗い
- **難易度**: ★★☆
- **長さ**: 約100マス幅
- **ギミック**: 落下ブロック、トゲ床、狭い通路
- **敵**: スライム × 6、ジャンプスライム × 4、コウモリ × 3
- **コイン**: 25枚
- **目標**: ゴールの扉に到達

**エリア構成**:
1. 洞窟入口（ジャンプスライム初登場）
2. トゲゾーン（精密ジャンプ要求）
3. 落下ブロックエリア
4. 空洞（コウモリ飛来）
5. 宝部屋（コイン密集）
6. ゴール扉

---

### Stage 3: 天空の城
- **テーマ**: 空中の城、積乱雲
- **難易度**: ★★★
- **長さ**: 約60マス幅（ボス戦含む）
- **ギミック**: 足場が少ない・風（横押し）
- **敵**: ジャンプスライム × 4、コウモリ × 5
- **コイン**: 15枚
- **目標**: ボスを撃破

**エリア構成**:
1. 城入口（全敵種登場）
2. 空中足場エリア（難関）
3. 城内部（前座の敵ラッシュ）
4. ボスルーム（閉鎖アリーナ、ボス戦）

## 5. アイテム仕様

### コイン
- 収集でスコア +100
- ステージクリア時にボーナス計算

### スピードアップ（★）
- 効果時間: 8秒
- 移動速度: 5.0 → 9.0 m/s
- 色: 黄色の星型

### 無敵（シールド）
- 効果時間: 5秒
- ダメージ無効
- 色: 青い盾型

### HP回復（ハート）
- HP +1 回復（最大5まで）
- 色: 赤いハート型

## 8. サウンド計画

### BGM
| シーン | 楽曲スタイル |
|---|---|
| タイトル | 明るく軽快なファンファーレ |
| Stage 1 | 元気なポップメロディ |
| Stage 2 | 不気味・洞窟っぽい |
| Stage 3 | 緊張感のある疾走感 |
| ボス戦 | 激しいバトル曲 |
| ゲームオーバー | 短く悲しいジングル |
| ゲームクリア | 爽快な達成感ファンファーレ |

### SE
- ジャンプ音 × 2（通常・二段）
- 攻撃音（剣振り）
- ヒット音（敵に当たった）
- ダメージ音（プレイヤーが被弾）
- コイン収集音
- アイテム収集音
- 死亡音
- ステージクリア音
- 足音（オプション）

## 10. 技術的な注意点

### レイヤー設定
```
Layer 0: Default
Layer 6: Ground       (地形・プラットフォーム)
Layer 7: Player       (プレイヤー)
Layer 8: Enemy        (敵)
Layer 9: Item         (コイン・アイテム)
Layer 10: PlayerAttack (プレイヤー攻撃判定)
Layer 11: EnemyAttack  (敵攻撃判定)
```

### タグ設定
```
"Player"    - プレイヤーオブジェクト
"Enemy"     - 敵オブジェクト
"Ground"    - 地面
"Coin"      - コイン
"Item"      - パワーアップアイテム
"Goal"      - ゴールオブジェクト
"DeathZone" - 落下死亡ゾーン
```

### Input Actions (Input System)
```
ActionMap: Player
  - Move: Vector2 (WASD / Arrow / Left Stick)
  - Jump: Button (Space / A Button)
  - Attack: Button (Z / X Button)
  - Pause: Button (Escape / Start)
```
